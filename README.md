# ShopKart E-Commerce Frontend

Frontend for the ShopKart e-commerce application, built with React and Vite.

## Features

- Product listing
- Product search
- Shopping cart
- Increase/decrease cart quantity
- User registration
- User login
- JWT authentication
- Logout
- Checkout
- Order creation
- My Orders section
- Responsive and professional UI
- Password show/hide option

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Fetch API
